================================================================================
NEWZ — HOURLY FREE SCRAPING + ANALYSIS SETUP GUIDE
================================================================================

Purpose: Activate automatic hourly article scraping (RSS + Cheerio, $0 cost)
and AI analysis on your deployed Vercel app. All code is already implemented;
this guide covers the manual setup steps only you can perform.

Prerequisites:
- GitHub account with this repo pushed
- Vercel account (free Hobby plan)
- Supabase account with a project created
- Google AI Studio account (free API key, no credit card)

================================================================================
STEP 1 — DEPLOY TO VERCEL (FREE HOBBY)
================================================================================

1. Push this repository to GitHub (git add, commit, push to your GitHub repo).
2. Go to https://vercel.com and log in.
3. Click "Add New Project" → "Import" → select your GitHub repo.
4. Framework preset: Next.js (auto-detected). Leave build settings at defaults.
5. Click "Deploy".
6. After deployment completes, note your production URL, e.g.:
   https://newz-abc123.vercel.app
   (You will need this URL in Steps 2 and 4.)

Do NOT add environment variables yet — do that in Step 2, then redeploy.

================================================================================

================================================================================
STEP 3 — APPLY SUPABASE SCHEMA AND SEED SOURCES
================================================================================

1. Go to https://supabase.com and open your project.
2. In the left sidebar, click SQL Editor → New query.
3. Copy the ENTIRE contents of the file:
   supabase/schema.sql
   Paste it into the SQL Editor and click "Run".
   Expected result: success message. Tables created: sources, articles,
   article_analyses, logs, source_feeds, oxylabs_schedules,
   oxylabs_schedule_runs, plus RLS policies and indexes.

4. Open another New query tab.
5. Copy the ENTIRE contents of the file:
   supabase/seed-sources.sql
   Paste it and click "Run".

6. At the bottom of seed-sources.sql there is a verification query:
   select name, listing_url, parser_strategy, rss_feed_url, is_active
   from public.sources order by name;
   Confirm it returns exactly 5 rows:
     Reuters        https://www.reuters.com        rss_feed_url set
     NPR            https://www.npr.org            rss_feed_url set
     BBC News       https://www.bbc.com/news       rss_feed_url set
     Fox News       https://www.foxnews.com        rss_feed_url set
     The Guardian   https://www.theguardian.com/us rss_feed_url set
   All should have is_active = true and rss_feed_url populated.

If any source has rss_feed_url = NULL, that source will be skipped during
scraping with a logged reason. The seed file backfills verified RSS URLs
for all 5 sources.

================================================================================
STEP 4 — ADD GITHUB REPOSITORY SECRETS
================================================================================

The free pipeline runs hourly via GitHub Actions (no Vercel Pro needed,
because Vercel Hobby allows cron only once per day). GitHub Actions calls
your deployed Vercel endpoints every hour at :15 UTC.

1. On GitHub, open your repository.
2. Go to Settings → Secrets and variables → Actions.
3. Click "New repository secret" and add:

-------------------------------------------------------------------------------
Secret name: APP_URL
-------------------------------------------------------------------------------
Value: Your Vercel production URL with NO trailing slash.
Example: https://newz-abc123.vercel.app
(Do NOT add / at the end.)

-------------------------------------------------------------------------------
Secret name: BIASLY_ADMIN_SECRET
-------------------------------------------------------------------------------
Value: The exact same string you set as BIASLY_ADMIN_SECRET in Vercel env
       vars (Step 2).

4. Save both secrets.

================================================================================
STEP 5 — ENABLE AND TEST THE GITHUB ACTIONS WORKFLOW
================================================================================

1. On GitHub, open your repository.
2. Click the "Actions" tab at the top.
3. On the left sidebar, find and click the workflow named:
   "Hourly free pipeline"
4. Click the "Run workflow" dropdown → "Run workflow".
5. Leave defaults (branch: main/master) and click the green "Run workflow"
   button.

What happens:
- Job "pipeline" runs on ubuntu-latest.
- Step 1: POST scrape to your Vercel /api/scrape-free (limitPerSource: 5).
- Step 2: POST analyze to your Vercel /api/analyze (all pending articles).
- Each step has a 10-minute timeout; expected total ~2–3 minutes.

After the workflow completes:
- Click the workflow run to view logs.
- You should see scrape output (candidates found, articles inserted) and
  analyze output (articles analyzed, sentiment/framing labels).

Going forward:
- The workflow triggers AUTOMATICALLY every hour at :15 UTC via
  `on: schedule: cron: "15 * * * *"`.
- It also runs on `workflow_dispatch` (manual trigger) whenever you click
  "Run workflow".

================================================================================
HOW THE HOURLY PIPELINE WORKS (ARCHITECTURE)
================================================================================

Vercel Hobby cron limit: once per day max. Hourly expressions fail deploy.
Therefore:

- Vercel daily crons (vercel.json):
    /api/cron/scrape-free   at 2:15 UTC daily (limit 2 per source)
    /api/cron/analyze-free  at 3:45 UTC daily
  These remain as a free daily fallback.

- GitHub Actions hourly (free, unlimited schedule on public repos):
    .github/workflows/hourly-pipeline.yml
    cron: "15 * * * *"   (every hour at :15 UTC)
    Steps: scrape (limitPerSource: 5) → analyze (all pending)

Idempotency:
- Scrape dedupes by original_url (chunks of ≤15 per .in() call per AGENTS §9).
- Re-scraping inserts 0 new rows; reports duplicatesSkipped.
- Analyze uses LEFT JOIN on article_analyses: only articles without an
  analysis row are processed. Already-analyzed articles are skipped.

Cost: $0.
- GitHub Actions: ~2 min/hour ≈ 1,440 min/month, within the 2,000 min free
  allowance for public repos.
- No Oxylabs credentials needed (RSS + Cheerio scraping).
- Gemini free tier: daily reset, no credit card.

================================================================================
TROUBLESHOOTING
================================================================================

- 401 on scrape/analyze: BIASLY_ADMIN_SECRET mismatch between Vercel env
  and the header you send. Double-check exact string (no trailing spaces).
- articlesInserted = 0 on first run: check Supabase sources table —
  rss_feed_url may be NULL for that source, or the RSS feed returned 0 items.
- Analysis status "failed" with missing-google-key: GOOGLE_GENERATIVE_AI_API_KEY
  not set in Vercel or not redeployed after adding it.
- Build fails: run `npm run typecheck` and `npm run lint` locally first.
- GitHub Actions workflow not showing: confirm the .yml file is committed and
  pushed to the default branch; check the Actions tab for workflow_dispatch
  availability.
